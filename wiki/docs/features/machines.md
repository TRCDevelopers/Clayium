# 機械

## ビルダー系

### 採掘器 / Block Breaker
**Tier 6** \
エネルギー不要で動作し、目の前の1ブロックを破壊する。
動作効率は範囲採掘器と同じ。\
液体関連の動作は未実装である。

### 範囲採掘器 / Ranged Miner
**Tier 8** \
粘土マーカーで指定された範囲を採掘する。右上のスロットにフィルターを置くことで、採掘するブロックを指定できる。\
**粘土レーザーを照射することで動作を加速できる。** \
加速率は、$r = (1 + 4 \log_{10}\left(\frac{\text{レーザーのエネルギー値}}{1000} + 1\right))$倍である。

1tickごとに $0.01 \times r$ CE 消費し、$100 \times r$ をprogressに加算する。\
ブロックの採掘に必要なprogressは、ブロックの硬さ $h$ に応じて決まる: $P := 400 \times (0.1 + h)$ \
なお、岩盤など硬さが-1のブロックは動作対象としない。

最大で1tickあたり10ブロックを採掘できる。この値はConfigで変更可能である。

::: info
以下の発展型の採掘機でもフィルター(幸運やシルクタッチ含む)の有無などでエネルギー・動作効率が変化することは無い。
:::

### 発展型範囲採掘機 / Advanced Ranged Miner
**Tier 9** \
範囲採掘器に、幸運・シルクタッチで採掘できる機能が追加されたもの。
それぞれに対応したフィルタースロットが追加され、マッチすれば幸運やシルクタッチがついた状態で採掘される。
幸運のレベルは3固定。

### 範囲置換機 / Ranged Replacer
**Tier 10** \
発展型範囲採掘器に、さらにブロックの置換機能が追加されたもの。

原作からの変更点として、採掘したブロックのみを置換するようになった。
